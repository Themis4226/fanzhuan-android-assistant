# 翻转外语助手：窗口使用说明

完整解压 Windows x64 便携包，双击 **翻转外语助手.exe**。保留同目录的脚本、runtime、tools，不能只复制 exe。

## 首次运行

1. 用数据线连接一台安卓真机，解锁，开启 USB 调试，并在手机上允许这台电脑。
2. 手动打开微信中的翻转外语，再点窗口的“检查连接”。可用“截图查看”“读取文字”和“手机投屏”核对当前页面。
3. 在“新建会话”明确选择自动答题/提交偏好。默认不授权自动答题或付费 API，模型额度为0。
4. 手机打开“今日任务”首页，选择“每日任务（自动衔接）”，点“开始运行”。运行结果与暂停原因显示在窗口下方。
5. “停止当前批次”会停止本窗口的 Python 任务及其子进程。已经发到手机的当前操作不会自动撤销。

## 任务模式

- 每日任务：依据首页剩余计数处理单词、拼写、语法、阅读和听力；验证列表和首页进度后再继续。
- 单词卡包：默认勾选连续处理下一包；可见编号卡包完成后，还会检查“单词拼写”入口。
- 其他任务（跳过单词）：只处理语法、阅读和听力，会保留未完成的单词与拼写。
- 听力 / 语法阅读单科：填写当前实际课程标题后运行。听力必须实际播放并观察播放次数增加。

语法/阅读直接选择首项、跳过已识别讲解，需要单独明确授权。跳过讲解不会跳过听力播放。
只有首页总数、所有分类计数和100%一致才确认全部完成；不会把提交次数当成完成证据。
独立的写作、技巧、口语任务或陌生布局仍需人工核对；“四级写作词汇”的拼写属于单词任务。

## 更换手机与恢复

停止当前批次，只连接并授权新手机，打开“今日任务”首页，再点“开始运行”。
启动器检查唯一 USB 真机，设备变化时建立独立会话，保留已用调用数与原上限，不复制旧手机进度或截图。
也可以先点“更换手机”只切换绑定。已完成的原会话保留证据，已关闭的授权需要显式新建。
运行中拔换手机会暂停，不会在答题过程中改绑另一台设备。RSA 授权仍由手机系统决定。

可以从已确认的拼写页面、匹配暂停检查点的单词卡包继续。
听力恢复须匹配当天已记录入口、课程及页数。没有有效检查点时，请先返回“今日任务”首页。
脚本更新后，停止旧批次再开始即可，无需为了更新而重置会话或额度。

## 拼写、弹窗和识别异常

拼写优先复用本机实际正确反馈或已接受的答案；未知题目只在原额度内请求文字模型。
题意提取和输入校验共用相同筛选规则，按当前字母空格数和 OCR 键盘定位输入，再核对进度。
模型等待后重新检查页面；同一课程、同一进度下题意不一致时最多读取3次，复读不调用模型或重复输入。
课程、进度变化，已有部分输入，答案长度不符或持续识别失败时会暂停。

听力已观察到的播放帮助“温馨提示”会确认一次并验证消失；后续页也会检查。
其他内容的弹窗不会一律点确认。听力仍需完成实际播放才能进入下一页。
通知横幅出现时最多等待15秒，期间不保存横幅画面、不上传、不点击。

## 费用与隐私

需要 DeepSeek 时，在本机复制 `.env.example` 为 `.env.local` 填写自己的密钥，并明确授权调用上限。
失败和超时也计入次数，不自动重试；次数上限不是金额硬上限。不要把密钥发到聊天或 GitHub。
模型只接收任务相关 OCR 文字，不发送原始截图、聊天、账号凭证或设备序列号。
会话、截图、授权、操作日志只在本机 `runs/` 中生成，不随发行包提供。
不要上传自己的 `.env.local`、`runs/`、ADB 授权文件或自用词汇记录。

## 验证与排错

- USB 未授权：保持解锁，在手机允许调试；没有弹窗时拔插数据线再检查。
- 无设备 / 多设备：使用可传输数据的数据线，只连接目标真机，必要时安装厂商官方驱动。
- 同一手机显示本次任务已完成：重复运行保护生效；新一天有真实任务时显式创建新会话。
- 另一个任务正在运行：停止原批次后再开始，不要并行控制同一手机。
- 页面变化、未知课程或额度耗尽：查看窗口原因，在手机核对后继续，不反复盲点。
- 查看本机 `runs/当前会话/events.jsonl`：包含操作、OCR 耗时和 `spelling_clue_recheck` 的预期/实际题意。

发行包的离线测试、OCR、窗口自检和迁移检查见 `PACKAGE_VALIDATION.json`。
这些验证不能保证任意课程和未来小程序布局无人监督运行，完整每日耗时也需实际测量。
